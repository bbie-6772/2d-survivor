# 0008. 주기 제어는 코루틴으로 한다

- 날짜: 2026-08-30 (D3)
- 상태: 채택

## 맥락

스폰 주기와 자동 공격 주기 두 곳에서 반복 타이머가 필요했다.

| | Update 타이머 | InvokeRepeating | 코루틴 |
|---|---|---|---|
| 상태 관리 | 필드로 노출 | 내부 | 상태 기계에 캡슐화 |
| 매 프레임 검사 | 있음 | 없음 | 없음 |
| 타입 안전성 | O | **X (문자열)** | O |
| 순차 시퀀스 표현 | 매우 어려움 | 불가 | **자연스러움** |

## 결정

`IEnumerator` + `while(true)` + `yield return _wait` 형태를 쓴다.
`WaitForSeconds`는 필드에 캐싱한다. **코루틴 시작은 `Start`에서 한다.**

## 이유

성능이 아니라 **웨이브 시퀀스 표현력**이 결정적이었다.
기획서에 "3분 중간보스 / 5분 최종보스", "BossPhase 동안 일반 좀비 스폰 X"가 확정되어 있다.
"5초 대기 → 10마리 → 3초 → 20마리 → 보스"를 Update 타이머로 짜면
웨이브 인덱스·현재 단계·잔여 마릿수를 전부 필드로 들고 `switch`로 관리해야 한다.
**손으로 상태 기계를 짜는 것**이고, 코루틴은 컴파일러가 그 상태 기계를 대신 만들어준다.

0003의 판단 방식과 동일하다. "언젠가 필요할지도"가 아니라 **문서에 적혀 있는 것**에 근거한다.

Update 타이머의 부수적 문제도 있다. 프레임이 튀어 간격의 2배가 흐른 경우
`_timer = 0`과 `_timer -= interval` 중 무엇을 쓰느냐로 주기가 조용히 밀린다.
코루틴은 이 선택 자체가 없다.

## 코루틴 시작을 `Start`에 둔 이유

- `SpawnLoop`의 첫 루프가 즉시 `_target.position`을 읽고 좀비를 만든다. **다른 오브젝트를 만지는 동작**이다.
- 씬 오브젝트들의 `Awake` 순서는 보장되지 않는다. 모든 `Awake`가 끝난 뒤에 `Start`가 돈다.
- **`enabled = false`는 코루틴을 막지 못한다.** `OnInit`(Awake 타이밍)에서 시작하면
  프리팹/타겟 가드가 실패한 스포너도 루프를 돌린다.
- `AttackLoop`도 첫 루프에서 물리 월드를 조회하므로 콜라이더 등록이 끝난 뒤여야 한다.

무기는 플레이어 자신에 붙어 `Awake`여도 순서 문제가 없지만, **일관성을 위해 `Start`로 통일**한다.
(컨벤션 1항: "일관성이 규칙 자체보다 중요하다")

## 함께 정리된 것 (`IEnumerator`의 정체)

- `IEnumerator`는 Unity 것이 아니라 .NET 표준 **순회** 인터페이스다.
  `yield return`이 있으면 컴파일러가 메서드를 상태 기계 클래스로 재작성한다(지역변수 → 필드, 진행 위치 → 정수).
- **스레드가 아니다.** 단일 스레드 협조형(cooperative)이며, 전환 지점이 `yield`로 코드에 명시되므로
  race condition이 원천적으로 없다. 대신 무거운 계산을 넘기는 용도로는 쓸 수 없다.
- stackless 구현이라 `yield`는 코루틴 본문에서만 가능하다(헬퍼 함수 안 불가).
- `WaitForSeconds`는 대기 기능이 아니라 **재개 시점을 알리는 표식**이다. 상태가 없으므로 캐싱해도 안전하다.
- `SetActive(false)`는 코루틴을 중단시키지만 `enabled = false`는 막지 못한다(비대칭).

## 대가 (인지하고 있음)

- **`WaitForSeconds` 캐싱은 인스펙터 값 변경이 반영되지 않는다.**
  스폰 간격은 웨이브 전환 시점에만 바뀌므로 문제없으나, **공격속도는 기획서상 약 제조로 상승하는 스탯**이다.
  스탯 변경 시 객체를 재생성하거나, 무적 시간처럼 `Time.time` 기반으로 전환해야 한다. 해당 위치 3곳(스포너·무기·연출).
- 코루틴 재개는 Update 이후이므로 `FixedUpdate`와 주기가 다르다.

## 재검토 시점

공격속도 스탯을 구현하는 시점(약 제조 시스템).
