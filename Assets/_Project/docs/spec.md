# 기획 작성

5분간 좀비가 만연한 도시를 돌아다니며 생존하고 최종보스를 물리치는 게임

---

## 코어 루프

플레이어는 카메라 중앙에 고정되며 시작한다.
WASD 를 이용해 이동하며 방향키를 이용해 공격방향을 정한다.
플레이어 주위로 좀비들이 다가오며 플레이어의 공격으로 좀비를 물리칠 수 있다.
좀비에게 근접하게 되면 플레이어는 피격을 받으며, 제공된 체력이 0이 되면 게임오버가 된다.
좀비가 죽으면 심장을 떨구며, 이를 주울수록 신체능력을 향상할 수 있는 약을 제조할 수 있다.
제조된 약으로 3가지 선택권이 주어짐 ( 능력치 강화 / 무기 교체(2종 택 1) )
메인 타이머 3분/5분 지난 시점에서 보스가 출현하며, 중간보스의 경우 메인 타이머가 멈추고 전용 타이머가 시작된다.
( 전용 타이머 내에 잡지 못할 시 보스가 광폭해진다. )

### 게임 상태

- Normal: 메인 타이머 진행. 일반 좀비 스폰.
- BossPhase: 메인 타이머 정지. 중간보스 전용 타이머 진행. // 최종보스의 경우 모든 타이머가 진행되지 않음
  - 일반 좀비 스폰 X
  - 중간보스 타이머 만료 시: 보스가 광폭화하며 광역 공격을 진행
- Result: 승리/패배 화면
  - 최종보스를 물리쳤을 시, 승리
  - 플레이어 체력이 0이 될 시, 패배

| 상태 | Normal | BossPhase | Result |
|---|---|---|---|
| Normal | 동일 | 2분/5분 도달 | 플레이어 체력 0 |
| BossPhase | 보스 체력/타이머 0 | 동일 | 플레이어/최종보스 체력 0 |
| Result | 재시작(씬 리로드) | X | 동일 |

### 타이머

- 메인: 최종 보스 출현까지 5분 (Normal 상태에서만 감소)
- 보스: 60초 (BossPhase 진입 시 리셋)
- 보스 출현: 3분(중간보스) 5분(최종보스)

### 보스 광폭화

보스 광폭화 이후 메인 타이머가 다시 돌아가며, 좀비 스폰도 정상화 진행됨
대신 보스는 이동속도 배수가 2로 증가하며 플레이어를 따라다닌다.
보스의 HP는 그대로 깎이며, 죽을 수 있다.

### 좀비 스폰

- 좀비는 한 스테이지에 동시존재 최대 300마리가 나오도록 한다.
- 플레이어 화면 밖에서 다가오도록 설계

### 무기 종류

- 몽둥이(기본) : 플레이어 앞 부채꼴 근접 공격
- 샷건(선택) : 투사체를 발사하는 광역 공격 (다발 저 데미지)
- 스나이퍼(선택) : 히트판정 관통 공격 (단발 고 데미지)

### 대시

- 거리: 플레이어 캐릭터 가로 기준 3~5배 정도 거리
- 쿨다운 : 1~2s
- 무적 여부 : 0.2~0.3s

## 플레이어의 행동가능 목록

기본적으로 행동: 조작방식 > 없다면 일어날 일 을 기록해둔다.

- 이동 : WASD (심장은 자동으로 줍는다. ) > 플레이어는 움직일 수 없다.
- 대시 : sapce > 좀비를 피해다니기 어렵다.
- 공격 방향 설정 : 방향키 ( 공격은 자동으로 진행된다. ) > 플레이어가 원하는 방향으로 공격을 할 수 없다.
- 약 제조 선택 : 1 / 2 / 3 숫자 > 플레이어의 자유도가 감소한다. (랜덤성도 재밌을 수 있다)

## 승리 / 패배 조건

- 승리조건 : 플레이어는 메인 타이머 5분에 나오는 최종보스의 체력을 0으로 만든다.
- 패배조건 : 플레이어의 체력이 0 이 된다.

## 만들지 않을 것

- 상점, 스킬트리 : 다회차 플레이에 대한 기획은 레벨 디자인의 영역으로 이번 프로젝트에 포함하지 않는다.
- 추가 스테이지 : 한 스테이지의 디테일과 구현에 목표를 두어 마감기한 내 제작할 수 있도록 제한한다.
- 리더보드, 멀티 플레이 : 게임 클라이언트보다 서버의 요소가 크기에 제외한다.
- 세이브, 로드 : 진행이 짧은 게임 특성상 로드기능의 필요성이 적다.
